# Descritivos dos exames (FAQ clínico)

Fonte: Procedimentos_GammaVet.md — aba descritivo. Usar para explicar o que é / para que serve / para quem, sem inventar.

Ver também tabela completa em `02_procedimentos_completos.md`.

Resumo rápido:
- **US Abdominal**: órgãos abdominais; cães/gatos
- **US Microbolhas**: caracterizar nódulos fígado/baço; exige US ≤30 dias
- **US Cervical**: tireoide/paratireoide/linfonodos
- **Eco**: coração + Doppler; pré-anestésico >6 anos
- **ECG**: atividade elétrica; pré-anestésico a critério
- **RX**: ossos/tórax/abdômen
- **TC**: cortes/3D; anestesia geral
- **Rinoscopia / Endoscopias / Bronco+Rino**: anestesia; visualização direta
- **Cintilografias**: medicina nuclear (renal, tireoide F/C, óssea, shunt, paratireoide)
- **Cistocentese**: coleta urinária guiada por US
- **Uretrografia / Urografia**: contraste urinário
- **Radioiodo F/C**: terapia I-131 + isolamento

Se o cliente perguntar detalhes clínicos profundos fora da KB → transferir humano.
